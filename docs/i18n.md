# i18n Guide

## Setup

i18next is initialised in `src/i18n/index.ts` and imported once in `src/main.tsx`. All translations are statically imported (no HTTP fetch) for Vite compatibility.

## Namespaces

| Namespace | File | Contents |
|---|---|---|
| `common` | `src/locales/{lang}/common.json` | Buttons, labels, pagination, empty states, confirmations |
| `auth` | `src/locales/{lang}/auth.json` | Login form labels, errors, SSO text |
| `navigation` | `src/locales/{lang}/navigation.json` | Sidebar menu items, topbar labels |

## Using Translations in Components

```tsx
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation('common');
  return <AppButton>{t('button.save')}</AppButton>;
}
```

For multiple namespaces:

```tsx
const { t: tCommon } = useTranslation('common');
const { t: tAuth } = useTranslation('auth');
```

## Adding a New Namespace

1. Create `src/locales/th/my-namespace.json` and `src/locales/en/my-namespace.json`
2. Import and register in `src/i18n/index.ts`:

```ts
import thMyNamespace from '../locales/th/my-namespace.json';
import enMyNamespace from '../locales/en/my-namespace.json';

i18n.init({
  resources: {
    th: { ..., 'my-namespace': thMyNamespace },
    en: { ..., 'my-namespace': enMyNamespace },
  },
});
```

3. Use: `const { t } = useTranslation('my-namespace');`

## Adding a New Locale

1. Create `src/locales/{code}/` and add all namespace JSON files
2. Add to `resources` in `src/i18n/index.ts`
3. Add language option to `SettingsPage` `LANG_OPTIONS` array

## Buddhist Era Date Handling

All displayed dates use Buddhist Era (พ.ศ.) — CE year + 543. Use the project utility:

```ts
import { formatDate } from '@/utils/format';

formatDate(new Date('2025-03-25'));           // → "25/03/2568"
formatDate('2025-03-25', { includeTime: true }); // → "25/03/2568 14:22"
formatDate(null);                              // → "-"
```

`AppDatePicker` automatically displays and outputs BE years in its label, while storing the underlying `Date` value in CE for API serialisation.

## TH/EN Toggle Implementation

The language toggle in `LoginPage` and `SettingsPage` calls:

```ts
void i18n.changeLanguage('en'); // or 'th'
```

This triggers a re-render of all components using `useTranslation`. The chosen language is persisted by i18next's `localStorage` detector plugin (if configured) or can be manually saved with `setItem('i18nextLng', lang)`.
